# 土佐弁の聞き取り

民生委員と要支援者は、土佐弁で話すことが多い。意味を取り違えると、欄の値や前提条件を誤る。
下の表は一般的な土佐弁の言い方である。地元の話者（民生委員など）に確認した言い方は、確認済みの印を付けて追加していく（現在は未確認）。

## 1. 意味を取り違えやすい言い方

| 言い方 | 意味 | 例 | 例の意味 |
|---|---|---|---|
| 〜しゆう | 〜している（動作が進行中） | 夜は2階で寝ゆう | 夜は2階で寝ている |
| 〜しちゅう | 〜してある・〜している（状態が続いている） | 杖ついちゅう | 杖をついている |
| よう〜ん、よう〜せん | 〜できない（できる力が無い） | あの階段はよう上がらん | あの階段は上がれない |
| よう〜する | よく〜する（回数が多い） | よう散歩しゆう | よく散歩している |
| 〜れん | 〜できない | 一人では立ち上がれん | 一人では立ち上がれない |
| おらん | いない | 昼は息子がおらん | 昼は息子がいない |
| 〜き、〜きに | 〜から（理由） | 足が悪いき | 足が悪いから |
| 〜やき | 〜だから | 70代やき | 70代だから |
| 〜けんど | 〜けれど | 声はかけてくれるけんど | 声はかけてくれるけれど |
| 〜がよ、〜ぜよ | 〜のだよ（強める） | 聞こえんがよ | 聞こえないのだよ |
| 遠うて | 遠くて（耳が遠うて＝耳が遠くて） | 耳が遠うて | 耳が遠くて |
| こじゃんと | とても、たくさん | こじゃんと時間がかかる | とても時間がかかる |
| まっこと | 本当に | まっこと急な階段 | 本当に急な階段 |
| いかん | だめだ | 夜はいかん | 夜はだめだ |
| ほいたら | それなら | ほいたら隣に頼む | それなら隣に頼む |

## 2. 扱い方

1. 「よう上がらん」は「上がれない」であり、「よく上がる」ではない。否定（〜ん、〜せん）が続くかを必ず確認する
2. 「〜しゆう」と「〜しちゅう」は、どちらも「〜している」と訳してよい。前提条件の判断（例: 2階で寝ている）には影響しない
3. 意味が分からない言い方は、決めつけずに未確認のままにし、追加の質問で確かめる
4. 引用（quote）は、標準語に直さず、原文の土佐弁のまま抜き出す
5. アプリが話す文（追加の質問）は標準語のやさしい言葉で書く。土佐弁で話す機能は、地元の話者が確認した言い方だけを使う（現在は使わない）

## 3. 音声認識の聞き違い（文字起こしの揺れ）

発言は、ブラウザの音声認識で文字にしたもの。音声認識は標準語に寄せて文字にするため、土佐弁の語尾や言い方が、別の語の文字になることがある。合成音声の土佐弁を音声入力で聞き取った試験（2026-11-08）では、次の聞き違いがあった。

| 話した言い方 | 文字起こし | 意味 |
|---|---|---|
| 〜しゆう（寝ゆう、働きゆう） | 〜しよう、〜しう（寝よう、働きう） | 〜している（「寝よう」は誘いではない） |
| 〜てくれゆう | 〜てくれよ | 〜てくれている（頼みではない） |
| 〜しちゅう | 〜中 | 〜している。前の語が消えることがある |
| 〜き（理由） | 気、駅（「ええ 駅」「出れる気」） | 〜から。文の切れ目の「き」が、別の語の漢字になる |
| 遠うて | 通って（耳が通って） | 遠くて |
| 〜がよ | 〜だよ | 〜のだよ |
| 〜のう、〜けんど | 〜の、〜けど | 語尾だけの違い。意味は変わらない |

扱い方:

1. 文の流れから聞き違いと分かるときは、意味をくみ取って欄に入れる。例:「隣の人がよう様子を見に来てくれよ」は「よく様子を見に来てくれている」なので、避難支援者と避難支援の方法に入れる
2. 引用（quote）は、文字起こしの文字のまま抜き出す（話した言い方に直さない）
3. 消えた語は補わない。文字起こしに無い語（道具・場所・人など）を推測して欄に入れない。その欄は未確認のままにする（アプリが追加の質問で確かめる）
