# やさしい言葉の書き方

読む人・聞く人は、スマートフォンの操作が苦手な高齢の民生委員と、要支援者である。文は画面に大きく表示され、音声で読み上げられる。

## 1. 決まり

1. 一文は短くする（目安は30字まで）。1文に1つのことだけを書く
2. 漢語を減らす（「徒歩で移動」ではなく「歩いて行く」、「就寝」ではなく「寝る」）。専門用語には短い説明を添える（例: 指定緊急避難場所（市が指定した避難先））
3. 責めない言い方にする。「この計画だと、ここで止まります」「ここを変えると、間に合います」
4. 子ども向けの言い方や、なれなれしい言い方をしない。丁寧語（です・ます）で書く
5. 感嘆符と絵文字を使わない。誇張しない
6. 追加の質問は1つの文で1つのことだけを聞く。はい・いいえか、短い言葉で答えられる聞き方にする（例: 「夜は何階で寝ていますか。」）

## 2. 数値の書き方（説明文）

- 問題点と改善案の説明文には、数値を直接書かない。数値は `{need_min}分` のようにプレースホルダーで書く。コードが計算の結果で置き換える
- 「十分」は「じゅっぷん」と「じゅうぶん」の区別がつかないので使わない。「じゅうぶん」の意味なら「余裕をもって」と書く
- 階は数字で書かない（「2階」は「上の階」、「1階」は「下の階」と書く）。時刻も数字で書かず「深夜」「明け方」と書く

## 3. 例

| 場面 | 良い例 | 避ける例 |
|---|---|---|
| 追加の質問 | 「100メートル歩くのに、何分くらいかかりますか。」 | 「歩行速度は何メートル毎秒ですか。」 |
| 問題点 | 「夜は着替えと明かりの準備で、家を出るまで{leave_min}分かかります。避難先に着く前に津波が来ます。{shortage_min}分足りません。」 | 「避難計画に重大な欠陥があります。」 |
| 改善案 | 「枕元に靴と明かりを置くと、{saved_min}分早く家を出られます。」 | 「準備を最適化しましょう。」 |
