# データの出典と加工の記録

この作品が使うデータと、各データの利用規約が求める出典の記載方法。データを追加・変更したときは、この表に1行追加する。

| ファイル | 元のデータ | 版・時点 | 加工 | 出典の書き方 |
|---|---|---|---|---|
| （地図）その場で読み込む | 地理院タイル（国土地理院） | | 無し | 「地理院タイル」と <https://maps.gsi.go.jp/development/ichiran.html> へのリンク |
| （地図）その場で読み込む | 重ねるハザードマップの津波浸水想定のタイル（高知県） | | 無し（半透明で重ねる） | 「津波浸水想定: 高知県（ハザードマップポータルサイト）」 |
| tosa_a40_h28.geojson | 国土数値情報 津波浸水想定（A40）高知県 | 平成28年 | 土佐市の範囲に切り出した | 「出典: 国土交通省国土数値情報ダウンロードサイト（URL）を加工して作成」 |
| tosa_shelters.json | 国土地理院 指定緊急避難場所データ | | 土佐市の分の、名前・座標・津波の対象かの区分だけ | 「出典: 国土地理院 指定緊急避難場所データ（URL）を加工して作成」 |
| tosa_arrival_times.json | 土佐市・高知県の津波浸水予測時間図（PDF） | 版を各行に | 図から場所・分を読み取って表にした | 各行に資料名・URL・ページ |
| 標高（手元に残す） | 国土地理院 標高 API | | 無し | 「出典: 国土地理院」 |
| samples/ | 自作（デモ用の架空の人物） | | | 架空の人と明記 |

ダウンロードした元のデータは `data/raw/` に置き、リポジトリに入れない（.gitignore 済み）。
