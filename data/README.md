ダウンロードした元のデータは `data/raw/` に置き、リポジトリに入れない（.gitignore 済み）。作り直すときは、元データを `data/raw/` に置いて次を実行する。

```bash
.venv/Scripts/python.exe -I scripts/build_data.py
```

## 指定緊急避難場所データの「ご利用上の注意」（国土地理院）

このデータを使った情報を第三者に提供するときは、次の点を正確に伝える。

1. 市町村長が指定した指定緊急避難場所を、各市町村が登録したデータである。最新でない場合や未掲載の場合があるため、最新の状況は土佐市に確認する
2. 指定緊急避難場所は、災害の種類ごとに指定されている。この作品は「津波」の対象の場所だけを避難先にする。「指定緊急避難場所」（緊急に避難する場所）と「指定避難所」（一定期間滞在する施設）は異なる
3. データは随時更新される
