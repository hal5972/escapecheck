# アプリの決まった文の読み（合成音声の台本）

アプリが読み上げる決まった文（追加の質問、最初の質問、聞き取りの終わりの文、サンプルの質問）と、合成音声に送る読みの一覧。`python scripts/make_voice.py questions` がこの表を読む。

- 表示の文は、画面に出す文と1文字も違わないようにする（違うと、スクリプトは音声を作らずに止まる）
- 読みは、漢字かな交じりで書き、読み誤りが分かっている語（web/readings.json の何分・間に合う・地名など）だけを、かなで書く。一覧の語が漢字のまま残っていると、スクリプトは止まる
- 下の表の読みは、最初に作ったときの方針で、すべてひらがなにしてある。音声はすでに作ったので、文を直すときだけ、その行の読みを漢字かな交じりで書き直す
- 間を空けたいところには、読点（、）を足してよい

|---|---|

| 避難のときに、声をかけてくれる人はいますか。 | ひなんのときに、こえをかけてくれるひとはいますか。 |
| 歩くときに、杖や車いすを使いますか。 | あるくときに、つえやくるまいすをつかいますか。 |
| どなたと暮らしていますか。 | どなたとくらしていますか。 |
| 市の防災の放送や、人の呼びかけは聞こえますか。 | しのぼうさいのほうそうや、ひとのよびかけはきこえますか。 |
| 津波のときは、どこへ避難しますか。 | つなみのときは、どこへひなんしますか。 |
| 避難先へは、どの道を通りますか。 | ひなんさきへは、どのみちをとおりますか。 |

| ほかに、避難のときに心配なことはありますか。 | ほかに、ひなんのときにしんぱいなことはありますか。 |
