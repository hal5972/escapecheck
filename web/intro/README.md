# 説明のアニメーション（`web/intro/`、`web/story/`）

デモ動画と、アプリの最初の案内で使う、2つのアニメーション。素の HTML・SVG・CSS（`@keyframes`）と最小限の JavaScript だけで作成した。ライブラリ、ビルドツール、外部からの読み込み、写真・ストック素材・生成画像は使っていない。

| ページ | 長さ | 内容 |
|---|---|---|
| `intro/`（はじめに） | 約25秒 | ① 宇佐の海辺の町と、民生委員 ② 地震と、津波が来るまでの時計 ③ 紙の様式とハザードマップを前に悩む民生委員（顔は描かない） ④「夜中に、本当に間に合う？」 ⑤ 話す・点検する・改善する → アプリへ |
| `story/`（仕組み） | 約11秒 | 話 → 聞き取りエージェント → 計画 → レッドチームエージェント ⇄ 計算ツール → フック → 検証エージェント → 人の承認 → 印刷。エージェントごとにモデル名を表示 |

## 操作

- ボタンは2つ。「一時停止」（止めると「再生」）と「最初から」。終わると「もう一度」と、「アプリを開く」（はじめにだけ）に変わる
- キーボード: スペースで再生と一時停止、R または Home で最初から
- 動きを減らす設定（`prefers-reduced-motion`）のときは、止めた状態で始まる
- 幅 800px 以下（スマートフォン）では、場面の文を枠の下に大きな文字で表示する

## 画面録画（動画の素材）

1. Chrome を全画面（F11）にし、画面の大きさを 1920×1080 にする
2. `/intro/?rec`（または `/story/?rec`）を開く。`?rec` を付けると、ボタンを隠して 16:9 の枠だけを表示する
3. 録画を始めてから、R キーで最初から再生する。スペースで一時停止できる

- 枠の下の約15%は、字幕を入れるために空けてある（字幕は編集で追加する）
- 動画の中のアニメーションは、合わせて40秒まで（2つで約36秒）
- ナレーションの音声が無くても再生できる

## 作り

- `player.css`・`player.js`: 2つのページで共通の再生画面。CSS のアニメーションを Web Animations API（`document.getAnimations()`）でまとめて操作する
- `intro.css`: 場面の長さは `:root` の `--d1`〜`--d5`（秒）。後ろの場面の開始時刻（`--t2`〜`--t5`）と全体の長さ（`--total`）は、積算で決まる
- `story.css`: 全体の長さ `--total` と、カード・矢印ごとの開始時刻
- 画面に出す文字は固定の HTML。JavaScript が書き換えるのはボタンと時間の表示だけで、`textContent` を使う（`innerHTML` は使わない）。サーバーの CSP に合わせ、インラインの script と外部の読み込みは無い
- SVG の `transform` 属性を持つ要素に、CSS の `transform` のアニメーションを付けると、位置が消える。内側の `<g>` に付ける

## 色と書体

アプリ（`web/style.css`）と同じ色と書体にそろえている。色の一覧は `web/README.md` の「色の一覧」。

- 基調色は藍。字幕の板・枠・ボタンは藍 700〜950、背景は藍 50〜300 と地（`#f2f4f8`）、判定の色は緑・黄・赤（記号と文字を添える）
- 仕組みの図の色: AI のエージェントは藍 700 の枠、データ（話・計画・印刷）は藍 300 の枠、コード（計算ツール・フック）は紫、人の承認は緑、止める印は赤
- 町の景色は、アプリの色の一覧にある色で描いた。一覧にない色は、木と丘の緑（`#2a9159` `#238853` `#14683a` `#55a175` `#3f8c5f`）と肌の色（`#f0c7a0` `#e5b58f`）だけ
- 書体は UD フォントを優先する（BIZ UDPGothic → Hiragino Sans → Noto Sans JP → Yu Gothic UI → Meiryo → sans-serif）。外部のフォントは読み込まない
- 文字と背景のコントラスト比は、すべて 7:1 以上（最小は 7.5:1）
- 最後の場面（はじめに）に、アプリのロゴ（`web/icon.svg` と同じ絵）を、題名の上とスマートフォンの上の帯に出している

## 数値と出典

- 画面に出す数値は「十数分」だけ。小さな注記に、基準（30cm の浸水までの時間）、出典（高知県の津波浸水予測、2012年）、版と場所で異なることを表示する。数値を変えるときは、注記も合わせる
- モデル名は、アプリのエージェントの設定（`app/config.py`）と同じ
